# Пропан — @gazpropan_uz_bot

Бу бошланғич версия: `/start` ва `/help` буйруқларига жавоб беради.
Шохобча, нарх, қидирув ва буюртма вазифалари ҳали қўшилмаган.
SQLite фақат қайта ишланган Telegram хабарининг рақамини сақлайди; мижозлар базаси эмас.

## Тайёр Windows дастурини олиш

1. GitHub репозиторийсида **Actions → Windows EXE** ни очинг.
2. Яшил белги билан тугаган охирги йиғишни очинг.
3. Пастда **Artifacts → PropanBot-Windows** ни босинг. GitHub аккаунтига кирган бўлишингиз керак.
4. Юкланган архивни очинг. Ичидаги `PropanBot-Windows.zip` ни ҳам очинг.
5. `PropanBot` папкасини оддий ёзиладиган жойга, масалан Documents ичига жойлаштиринг.
6. `START.bat` ни босинг. Биринчи марта `.env` файли яратилади ва Блокнотда очилади.
7. `TELEGRAM_BOT_TOKEN=` дан кейин BotFather берган токенни ёзинг. Сақланг ва Блокнотни ёпинг. Токенни чатга юборманг.
8. `START.bat` ни яна босинг. Telegram’да @gazpropan_uz_bot га `/start` юборинг.
9. Тўхтатиш учун `STOP.bat` ни босинг. 45 сониягача кутинг ёки бот ойнасида Ctrl+C босинг.

Windows 10/11 x64, интернет ва компьютернинг ёқилган ҳолатда туриши керак.
Python ўрнатиш шарт эмас. GitHub Actions ботни 24 соат ишлатмайди, фақат EXE йиғади.
Бир токен билан бошқа серверда ишлаётган бот бўлса, аввал уни тўхтатинг.
Агар webhook ёқилган бўлса, дастур уни ўзбошимчалик билан ўчирмайди.

## Файллар ва хавфсизлик

- `.env.example` — токенсиз намуна; `.env` — фақат ўз компьютерингиздаги сир.
- `data/propan.sqlite3` — биринчи ишга тушганда автоматик яратилади.
- `run/` — ботни тўхтатиш ва иккинчи нусха ишлашини чеклаш учун.
- `.gitignore` токен, сессия, базалар ва ишчи папкаларни Git’дан чиқаради.
- ZIP фақат EXE, икки BAT, токенсиз намуна ва ушбу йўриқномадан йиғилади.
- Токен GitHub Secrets’га ҳам керак эмас: йиғиш ва тестлар токенсиз ўтади.
- `.gitignore` олдин юкланган сирларни ўчирмайди. `.env` ни ҳеч қачон `git add -f` билан қўшманг.

## Қайта йиғиш

Код `main` га юборилганда йиғиш автоматик бошланади. Қўлда: **Actions → Windows EXE → Run workflow**.
Артефакт 14 кун сақланади; кейин қайта йиғиш мумкин.

`python propanbot.py --self-test`
