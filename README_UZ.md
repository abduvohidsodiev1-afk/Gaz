# PropanBot — янги тоза Windows тўплами

Версия: **PropanBot-2026.10.28**. Бот: **@gazpropan_uz_bot**.
Ягона манба гуруҳи: **@propan_uzbekistan_2026**.
Windows 10/11 x64 учун. Python ўрнатиш шарт эмас.

## Эски версиядан ўтиш — фақат икки нарсани сақланг

1. Эски папкада `STOP.bat` ни босинг. Ботнинг ишчи ойнаси тўлиқ ёпилишини кутинг.
2. Эски **`.env` файли** ва бутун **`data` папкаси**нинг захира нусхасини олинг.
3. GitHub Actions'дан янги `PropanBot-Windows` архивини юкланг ва алоҳида папкага очинг.
4. Эски `.env` ва `data` ни янги папкага нусхаланг.
5. `TEKSHIRISH.bat` ни босинг: версия ва `SELF-TEST OK` чиқиши керак.
6. `START.bat` ни ишга туширинг. Гуруҳда `/status` юборинг: `PropanBot-2026.10.28` кўринади.
7. Янги бот ишлаганини текширгач, эски дастур файллари керак бўлмайди. Захирани сақлаб туринг.

Бир вақтда эски ва янги ботни ишлатманг. `.env` ни қайта тўлдириш ёки токенни қайта олиш керак эмас.
`data` ичидаги базани алоҳида файлларини танлаб эмас, папкани тўлиқ кўчиринг.
Архивда ҳақиқий `.env` ва `data` йўқ; янги дастур сиз нусхалаган маҳаллий файллардан фойдаланади.
Ишлатилган каталог, хабарлар ва нархлар SQLite'да сақланади; эски catalog.json'ни кўчириш талаб қилинмайди.
Янги `.env.example` фақат токенсиз намуна. `.env` мавжуд бўлса, START уни алмаштирмайди.

## Тўпламдаги файллар

- `PropanBot.exe` — дастур; `START.bat` — ишга тушириш; `STOP.bat` — тўхтатиш.
- `TEKSHIRISH.bat` — токенсиз ички текширув ва версия.
- `IMPORT_HISTORY.bat` — Telegram Desktop JSON тарихидан охирги 1000 хабарни импорт қилиш.
- `AI_TEST.bat` — 59 ҳолатли аввалги AI синови.
- `AI_DIAG.bat` — вазифалар/JSON форматлари бўйича диагностика.
- `AI_HYBRID_TEST.bat` — AI ва ҳимояни алоҳида ҳисоблайдиган гибрид синов.
- `.env.example`, `catalog.example.json` — шахсий маълумотсиз намуналар.
- `RELEASE_INFO.json` — версия, GitHub commit ва тўплам файлларининг SHA-256 қийматлари.

Синов бат-файлларини оддий ишлашда босиш шарт эмас. Бот учун асосийлари START ва STOP.

## Бот нима қилади

Гуруҳда шохобча нархи, манзили ёки очиқлиги ҳақида саволни қабул қилади.
Лотинча саволга лотинча, кириллчага кириллча жавоб беради. Саволда `?` шарт эмас.
«қанча/канча», «qanaqa/qnaqa», «қандай», «айтворила» каби шакллар қўлланади.
Ҳар қандай эркин хабарни 100% тушуниш кафолатланмайди.

Инсон жавобини **30 сония** кутади. Аниқ Reply ёки савол берувчини белгилаб юборилган
`8200` каби жавобни шохобчага боғлаб сақлайди; инсон жавоб берса бот такрорламайди.
Бир одам икки хил шохобча ҳақида сўраган бўлса, фақат унга тегишли белги билан келган
рақам қайси саволники эканини тахмин қилмайди. Аниқ саволга Reply қилиш керак.
Ҳеч ким жавоб бермаса, базадаги охирги маълумот чиқади.

«Майорский 8200» каби маълум шохобча номи + рақам шакли ҳам қабул қилинади.
«8200данми» савол; у тасдиқланган нарх деб сақланмайди.
Нарх, ҳолат ва уларнинг манба хабарлари алоҳида сақланади. Нархнинг ўзидан очиқлик хулоса қилинмайди.
Карточкада фақат **Нарх манбаси · Ҳолат манбаси · Мўлжал** тугмалари бор.
Манба йўқ бўлса, сохта ҳавола ўрнига маълумот сақланмагани айтилади.

28 та берилган локация ва Сассу атрофидаги қўшимча мўлжаллар дастур ичида бор.
Берилган эски рўйхатдаги нарх ва очиқ/ёпиқ белгилари дастлабки маълумот сифатида олинмаган.
Иш вақти — эълон қилинган жадвал; 24/7 ёзуви ҳозир газ борлигини тасдиқламайди.
№6 Янги Ўзбекистон ва №19 Қибрай IBR алоҳида. Сергели №10/№11 ҳам алоҳида.
Кўприк атрофидаги «8/9-заправка» лақаблари рўйхатнинг №8 Қумариқ/№9 Нўғойқўрғон рақамлари билан бирлаштирилмайди.
Кофе/Қизил — бир шохобча. Ноаниқ умумий кўприк номи келса, аниқлаштириш сўралади.

Буйруқлар: `/status`, `/help`, `/stations`, `/prices`, `/masters`, `/names`.
Меню ва ёрдам буйруқлари дарҳол; шохобча ҳақидаги саволлар 30 сониялик тартибда ишлайди.

## Telegram ҳуқуқлари

Гуруҳ админи ботни қўшиши, барча хабарларни ўқиш ва ёзишга рухсат бериши керак.
BotFather: `/setprivacy` → @gazpropan_uz_bot → Disable. Зарур бўлса ботни гуруҳга қайта қўшинг.
Ишлаш учун компьютер, интернет ва START ойнаси ишлаб туриши керак.
GitHub Actions ботни доимий ишлатмайди, фақат Windows дастурини йиғади.

## Аввалги 1000 хабар

Bot API ўтмиш тарихини олмайди. Бир марта Telegram Desktop'да гуруҳ → уч нуқта →
«Экспорт истории чата» → JSON ни танланг. Медиа шарт эмас; сана оралиғи камида 1000 хабарни қамрасин.
Ботни тўхтатинг, `IMPORT_HISTORY.bat` орқали `result.json` ни танланг. Бошқа гуруҳ экспорти рад этилади.
Импорт эски саволларга гуруҳда жавоб ёзмайди. Олдин базанинг маҳаллий захираси яратилади.
Кейин START'ни босинг. Янги келаётган охирги 1000 хабар маҳаллий сақланиб, қайта ишга тушишда таҳлил қилинади.
Компьютер узоқ ўчса, Bot API ўтказиб юборган тарих учун янги JSON импорт керак бўлиши мумкин.

## Маҳаллий AI ҳолати

**AI асосий ботга ҳали уланмаган; ҳозир фақат синов бат-файлларида ишлайди.**
Уларнинг учун компьютерда Ollama ва `qwen2.5:3b` ўрнатилган бўлиши керак.
Улар бот архивига қўшилмайди. Аввал ўрнатилган Ollama ва модель компьютерда қолади; қайта юклаш шарт эмас.
Синовлар токен ёки базага тегмайди, Telegram'га хабар юбормайди; фақат `127.0.0.1:11434` га мурожаат қилади.
Натижалар `ai-test-results` папкасида. Коднинг unit-тестлари AI аниқлиги дегани эмас.
Гибрид қисмда код натижаси ва AI натижаси алоҳида ҳисобланади; маълум 59 та мисолдан ўтиш янги хабарларга кафолат эмас.
